# UniTruck — E-commerce (CRUD)

> 🚧 Em desenvolvimento: estrutura inicial do front-end

Front-end de um e-commerce com operações de CRUD de produtos, feito em **React 19 + Vite** e estilizado com **Tailwind CSS 4**.

## Tecnologias

React 19 · Vite · Tailwind CSS 4 · ESLint

## Como rodar

```bash
git clone https://github.com/talles1x/Ecommerce-UniTruck-CRUD.git
cd Ecommerce-UniTruck-CRUD/frontend
npm install
npm run dev
```
